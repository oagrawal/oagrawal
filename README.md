# Hey! 👋
I’m **Om Agrawal**, a Computer Science student at **UT Austin**, finishing an Integrated Master’s (B.S. + M.S.) in 2027.

This fall I’m joining **Canyon Code** as an **ML Systems Engineer Co-op**, working on their agent dependency graph, which batches and prioritizes model calls across multi-agent workflows.

With the **UT Networked Systems Research Group**, I work on inference efficiency for video diffusion models. Our paper [**ACID: Adaptive Caching for vIDeo generation**](https://arxiv.org/abs/2607.12358) presents a training-free mechanism that switches feature-caching thresholds during the denoising procedure, reaching up to 2.16× speedup over the no-caching baseline and 38% additional speedup over conservative fixed-threshold caching, with negligible quality loss.

At **Anduril**, I shipped the official [**Lattice Agent Skills**](https://github.com/anduril/lattice-sdk-ai) ([docs](https://developer.anduril.com/guides/developer-tools/skills)), which teach coding agents to integrate against Anduril's Lattice APIs across languages, REST/gRPC protocols, and auth methods. The core of the work was the agent evaluation infrastructure behind them: realistic integration tasks, sandboxed headless agent runs, graders scored against live Lattice deployment state, and a weekly CI feedback loop that flags regressions as the APIs evolve.

Previously, I designed a [unified networking protocol](https://www.foreflight.com/connect/spec/) for the ForeFlight Connect platform at **Boeing · ForeFlight**, built GPS interference detection and jamming localization algorithms at the **Federal Aviation Administration**, and was a **Course Assistant** for Discrete Mathematics at UT Austin.
